# Re-kNN

> **「ベクトル検索は、サイコロに依存するべきではない。」**

[English README](./README.md)

Re-kNN は、現代的なベクトル検索エンジンのアーキテクチャの中で kNN を再構築したもので、評価指向のベクトル検索・推論ライブラリです。
決定論的な幾何構造、動的更新、明示的な未知検出に重点を置いています。


従来の手法とは異なり、各結果に対して明示的かつ再現可能な根拠を提供します。そのため、意思決定や監査に敏感な環境での評価に適しています。

## 重要な注意事項

Re-kNN は現在、評価指向のリリースとして提供しています。

Re-kNN の主な強みは、単純な検索速度だけでなく、決定性、再現性、明示的な根拠提示、そして未知データへの対応能力にあります。

## ユースケース

Re-kNN は、説明可能性、再現性、未知検出能力が重要となるシナリオを想定して設計しています。

代表的なユースケースは以下の通りです。

- **検査工程改善**  
  小規模データから運用を開始し、データの逐次登録によって時間とともに性能向上を図る検査システム。
- **エッジ推論**  
  CPU・メモリ資源が限られた単体デバイス上で行うリアルタイム推論。
- **異常検知**  
  既知データまたは正常データのみを登録することによって未知状態を検出する仕組み。
- **ナレッジ検索**  
  明示的な根拠提示、センテンス単位のスコアリング、再現可能な出力が求められる検索システム。

より詳細なユースケースや適用アイデアについては、以下を参照してください。  
[`USECASES.ja.md`](./docs/USECASES.ja.md)

## 技術的特徴

- 決定論的なベクトル検索
- 明示的な近傍根拠の提示

- 安定かつ再現可能な出力

### 標準サポート次元

Re-kNN は、主要なドメインにおいて即時に評価できるよう、以下のベクトル次元を標準的にサポートしています。

* **Text Domain**: 768 次元（対象: `bert-base-multilingual-cased` により生成されたテキスト埋め込み）
* **Pattern Domain**: 784 次元（対象: 特徴抽出なしの MNIST 生ピクセルベクトル）
* **Vision Domain**: 3072 次元（対象: 32×32×3 RGB 画像をフラット化した CIFAR-10 生ピクセルベクトル）

CIFAR-10 の評価では、Re-kNN は他モデルによる埋め込みや特徴量を用いず、元の画像ピクセル値をそのまま 3072 次元ベクトルとして使用しています。

これらの次元は参照用の評価対象として提供されています。その他の次元要件についても、Re-kNN のコア幾何構造はカスタム実装によって適用可能です。

## Manifesto

- **ReBuild**: ベクトル検索エンジンの基本アーキテクチャをゼロから再構築します。
- **ReNewal**: kNN と現代的なベクトル検索エンジンを組み合わせ、大規模要件に適応した形へ更新します。
- **ReCall**: 決定論的な探索挙動と明示的な unknown 処理で、検索と推論における不要な不確実性を減らします。
- **ReFine**: DB 構築後の refinement により高次元幾何を継続的に最適化します。Re-kNN は、検索ツリー内で構造的に不適切な位置に置かれた要素を再評価し、構築後に補正できます。

## コード例

Re-kNN は、登録、検索、削除、refinement のためのコンパクトな API を提供している。

```csharp
// 1. エンジンを初期化
Initialize(ModeEnum.MNIST, 1);

// 2. ベクトルを登録
Add(0, vec, length, mainId, subId, 5, 0.9);

// 3. 推論を実行
PredictResult* result = Predict(0, vec, length, kValue, 0.7);

// 4. 文書を削除
Delete(0, mainId, subId);

// 5. 必要に応じて rebuild / refine
RefineAll(0, -1);
```
