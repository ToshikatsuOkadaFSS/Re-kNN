# Re-kNN のアーキテクチャ

## コア思想

### 決定論的幾何構造

Re-kNN は、乱数や乱数シードに依存せず、**決定論的幾何構造**に基づいて検索を行う。  
同一の入力条件のもとでは、システムは常に同一の結果を返す。

### 密度ベースの分割

空間分割は、データの**自然な密度**に基づいて行われる。

### データを切り捨てない

**量子化ではなくクラスタリング。**  
従来手法がメモリ削減のためにベクトル精度を切り捨てるのに対し、Re-kNN は密度に基づく高忠実度なクラスタリングを採用する。  
構造的に効率的な方法でデータを整理しながら、元のデータの完全性を維持する。

### 逐次順序の受容

Re-kNN は、データ挿入の順序によって木構造が変化し得ることを受け入れる。  
私たちは「時間の流れ」を構造上の現実として受け止める。  
挿入順序は最終的な構造に影響を与えるが、固定された挿入順序のもとでは、システムは依然として決定論的である。

### ソートに依存しない構成

Re-kNN は、高次元データに対して 1 次元ソートを主要な構成原理として用いない。  
その代わりに、空間そのものの構造的性質に従ってデータを編成する。

### Honest Predict

Re-kNN は、各推論に対して、対応した近傍、距離、未知または警告インジケータなどの補助情報を提供する。

### Honest Unknown

対象データが未知である場合、それを明示的に通知する。  
私たちは、無理に推測するよりも**知的誠実さ**を優先する。

### 動的知識保守

知識は静的ではない。  
Re-kNN は、追加、削除、最適化といったリアルタイムな変更を可能にし、データベースが保持する情報とともに進化し続けることを保証する。

### 構築後の自己補正

データベース構築後、Re-kNN は検索木の中で構造的に不適切な位置に配置された要素を再評価し、refinement によって補正することができる。
