# Re-kNN のコンセプト

## キーコンセプト

Re-kNN は、単なる高速なベクトル検索エンジンではない。

検索結果を次のようなものにすることを目的として設計されている。

- 説明可能であること（なぜこの結果なのか？）
- 再現可能であること（同じ入力 → 同じ出力）
- 検証可能であること（この結果を信頼できるか？）

## コアバリュー

- 各結果に対する明示的な根拠
- 決定論的な挙動
- 安定した説明（乱数に依存しない）
- 未知データへの対応
- 現実の意思決定文脈における評価に適していること

## 説明性とハルシネーション検証

### 課題

多くのナレッジ検索システムでは、結果は返されるものの、  
その結果に至った理由が不明確であることが多い。

これは、ハルシネーションが懸念される環境では特に重大な問題となる。

- 利用者は、その結果が信頼できるかどうかを検証できない
- 誤った結果を分析したり改善したりできない
- 意思決定や監査において、そのシステムを信頼できない
- ハルシネーションが疑われる場合でも、検証が困難である

### Re-kNN のアプローチ

Re-kNN は、各結果に対して明示的かつ再現可能な根拠を提供する。

- センテンス単位の類似度スコア
- 推論根拠としての近傍データ
- 決定論的な出力（同じ入力 → 同じ結果）

### 効果

- ハルシネーションが疑われる場合の検証を可能にする
- 利用者が「なぜこの結果なのか」を理解できるようにする
- 誤り分析やシステム改善を可能にする
- 意思決定および監査ワークフローを支援する
