# Re-kNN のユースケース

> **関連ドキュメント:**
>
>   - [MNIST による性能評価エビデンス (EVIDENCE.MNIST.ja.md)](EVIDENCE.MNIST.ja.md)
>   - [CIFAR-10 による性能評価エビデンス (EVIDENCE.CIFAR-10.ja.md)](EVIDENCE.CIFAR-10.ja.md)

Re-kNN の特徴である、省メモリ、低レイテンシ、柔軟性、未知検知性能が活用できるユースケースとして、以下のものを挙げる。

各ユースケースでの適用は今後の課題である。

| ユースケース | 重視する性能 | 推奨未知判定閾値 | 特徴 |
| :--- | :--- | :--- | :--- |
| **検査工程改善** | 柔軟性・説明性 | $\ge 0.9$ | **スモールスタート**のシステム運用 |
| **エッジ推論** | 低負荷・速さ | $\ge 0.5$ | デバイス単体での**リアルタイム判定**・**エッジ完結** |
| **異常検知** | 未知検知能力 | $\ge 0.9$ | **正常データ**を中心とした異常検知 |

## 1. 検査工程の改善
検査工程の課題は、事前に判定用のデータを大量に用意することが難しいことである。
Re-kNN の柔軟性と未知検知性能は、この課題に対する有効なアプローチとなる可能性がある。
- **シナリオ**: スモールスタートでの検査システム
- **訴求ポイント**: 未知として検出されたデータを追加登録することを繰り返すことで、**運用しながら性能を向上させる**。
- **適用方針**: 小規模データで運用を開始。運用中に発生した誤検知データ・未知データを随時インデックスに追加する。
- **パラメタ設定**: 未知判定閾値を高く設定($\ge 0.9$)。これにより、未知データを積極的に検出する。
- **メリット1**: **少ないデータ**からでも運用が開始できる。
- **メリット2**: データの逐次追加・削除による**ダウンタイムなし**での運用。
- **メリット3**: 不良判定の**根拠**の提供。**根拠**を用いた不良解析。
- **デメリット1**: データ不足時には判定精度が安定しない。多くのデータが**未知**と判定される。
- **デメリット2**: 運用初期のデータ登録コスト。初期に多くのデータを追加する必要がある。
- **優位点1**: 未知データの検出。
- **優位点2**: データの逐次追加・削除。

## 2. エッジデバイスでの推論
エッジデバイスでは、低リソースで推論することが求められる。多くの場合は低次元のデータである。
異なる環境に置かれることが多いため、エッジデバイス単位でのインデックス調整も求められる。
Re-kNN の省メモリ性能と低レイテンシ性能は、この課題に対する有効なアプローチとなる可能性がある。
- **シナリオ**: センサを搭載した自律運用デバイスで推論
- **訴求ポイント**: エッジデバイス上でのインデックスの調整。
- **適用方針**: 比較的少ない CPU・メモリ資源での逐次登録・推論。
- **パラメタ設定**: 未知判定閾値を運用向けに設定($\ge 0.5$)。これにより、未知の発生割合を削減。
- **メリット1**: リソース消費が抑えられるため、エッジデバイスの単価削減が可能。
- **メリット2**: 運用環境に合わせた調整を、エッジデバイスで完結。
- **デメリット1**: 追加登録数が増えることにより、将来のリソース消費の上昇。
- **優位点**: 低コストでのインデックスのメンテナンス。

## 3. 異常検知
異常検知の課題は、異常データを集めることが困難であることである。
Re-kNN の未知検知性能は、この課題に対する有効なアプローチとなる可能性がある。
- **シナリオ**: 未知の状態の検知が要求されるシステム(セキュリティ分野)
- **訴求ポイント**: 既知データのみを登録するだけで、未知データの判定ができる。
- **適用方針**: 未知の異常は、随時異常データとしてインデックスに追加。
- **パラメタ設定**: 未知判定閾値を異常検知向けに設定($\ge 0.9$)。これにより、未知データを積極的に検出する。
- **メリット1**: 積極的に未知データを検出することで、異常の見逃し(偽陰性)を削減。
- **メリット2**: 既知の異常にラベルをつけて保存することで、既知の異常を検出。
- **デメリット1**: 全ての未知データが検出できるわけではないため、他の検知手法との併用が必要となる場合がある。
- **優位点**: 再学習ではなく逐次登録によって異常検知性能を改善できる可能性がある。
